# Murmurgrove Phase 2.4 — Organic Reframe

## Scope
This patch preserves all frozen source data, archive logic, real topology, snapshot hashes, and navigation integrity.
Only the presentation layer and everyday UI were reworked.

## What changed

### 1) Organic curve language
- Higher-subdivision organic spline sampling retained from the existing render layer.
- Tube and ribbon rendering now taper naturally toward both ends.
- Fiber, fossil, pulse, sediment, and veil surfaces avoid hard cut endings and polygonal edge feeling.
- Stronger membrane-style Fresnel attenuation and softer Gaussian falloff.

### 2) Everyday minimal interface
- Default interface now hides the large lab-facing control surface.
- Search and settings are folded into two minimal corner buttons.
- Archive search can still open any record.
- Lab controls (A/B/C, T0/T1/T2, reset, blind, FPS) remain available inside the settings panel.
- Detail reading panel simplified toward a gallery-label mode.

### 3) Functional color system
- Writing / propulsion tissues: deep teal-indigo family.
- Exhibitions / pulse chambers: warm amber-gold family.
- Concepts / veil: sage and mist-lilac translucent field.
- People & Institutions: pearl / warm neutral node presence.
- Old fossil layers and inactive substrate remain restrained bone / silver / smoke-brown.

### 4) Stronger visible life rhythm
- Whole-body tidal breathing motion increased.
- Fibers now sway with a more legible wave-like motion.
- Pulse chambers and cores carry clearer flowing light rhythm.

## Integrity
- Frozen data files remain unchanged.
- No archive logic, true topology, or snapshot pins were modified.
- Full test suite passed: 57 / 57.
