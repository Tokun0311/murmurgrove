# Concepts network update

- `/concepts/` now shows a static linked concept cloud instead of an ordered list.
- All labels link to the existing concept pages. The connections are calculated from co-occurring concepts in exhibition metadata, not inferred causal influences.
- No animation loop, simulation library or third-party script; an optional tiny hover/focus script only highlights existing connections.
- Mobile: horizontally scrollable map at readable word size.
- Original content and Institutions zoom map are preserved.
