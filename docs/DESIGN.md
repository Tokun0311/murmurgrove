# Design invariants

- Unified emerald, restrained light and open space; no closed rectangular borders in the public UI.
- Whole remains the default observation mode. No default node labels; active selection reveals existing text.
- An already existing organism is encountered, not launched. Existing records start at mature positions; the entrance camera is distinct from node growth. Preserve the approved camera timing, desktop/mobile gesture behavior, relation navigation and compact mobile panel.
- Real, evidenced archive relations only. No invented nodes/edges for decoration; isolated records remain discoverable. History preserves observed/reconstructed distinctions and withdrawals take precedence.
- Future performance work must preserve all records, relations, interaction and design; prefer fewer invisible calculations over more effects.
