murmurgrove editor v1.3 · Exhibition-first / Clear workflow

安装（与 v1.2 一样）：
1. 关闭正在运行的旧 Editor 和黑色 CMD 窗口。
2. 解压 ZIP，将 murmurgrove-editor 文件夹复制进原网站项目根目录，合并文件夹并替换同名文件。不要先删除旧文件夹，不要删除 .private。
3. 双击 START-EDITOR.bat。首次启动自动检查版本，备份旧程序后更新。支持此前交付的 v1.2 和未升级的 v1.1。打开 http://127.0.0.1:4317。
macOS 可运行 bash START-EDITOR.command。无须 npm install。

日常：01 Capture 填基本资料和正文；02 Connect 选择概念、搜索人物/机构或新建；03 Publish 保存私稿，核实后选择写入公开本地文件。网站上线仍由你通过 GitHub Desktop 审核、Commit、Push。
- Concepts 默认列出所有尚有效的已有概念，可多选，搜索只是筛选；已合并的旧概念以别名检索，不重复列出。
- Venue 是实际发生地点，Main institution 是机构档案，可不同；如果两者同名，可以一键把机构名称复制到场地，不会自动覆盖。
- 红色：必填错误/无法发布；橙色：待审核/需要处理；绿色：已选择/已审核/基本字段齐备；蓝色：编辑状态。绿色不代表事实已经核实。
- 新建关系可直接填写名称、可选说明和 URL ID；中文日文名称可自动生成稳定 ID。提交前仍需审查每条新增记录。
- 高级关系分析默认折叠，Research 工作区保留。

保护：升级只修改本地 Editor 程序文件。原始文本、私人草稿、公开档案、生命体、网站设计和 IndexNow 不会因安装而修改。备份在 .private/editor-upgrade-backups。切勿把 .private 上传 GitHub。

测试：继承的 7 项批量发布测试通过；在模拟浏览器中使用 75 个虚构概念验证默认全量显示、选择、别名筛选、中文概念创建（摘要 API 在测试沙箱内使用替身）、审核、必填提醒、Venue 复制与 375px 窄屏。此模拟并非真实 Windows/完整编辑器端到端测试。首次启动有 JS 语法检查；先用私人草稿试用再发布。
