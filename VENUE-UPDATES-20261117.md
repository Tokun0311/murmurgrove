# Venue updates from user-submitted CSV (2026-11-17)

Source: `tow-archive-addresses-remaining-20261117(1).csv`, supplied by the archive owner.

Records were updated to show named venues (when specified) instead of ambiguous placeholders such as 'Phuket', 'Busan', and 'Tokyo'. The related event or biennial identity is preserved. `venueAddress` marks a supplied activity venue address, not a verified permanent mailing address for the whole festival. `venueStatus: user-supplied` indicates that this has not been independently verified.

Art Week Tokyo / Otemachi: SMBC East Tower was described in the source as a *historical reference*, not a confirmed location for the recorded event. It remains labeled `reference`, and the public list retains the project name instead of presenting that building as confirmed.

The geographic map still uses approximate city locations unless precise longitude/latitude is entered in the institutional content. No street-level coordinates were fabricated.
